# Her Photos Directory

Place Anushree's photographs in this folder!

## Quick Guide

1. Add her photo files here with these names (or any filenames you prefer):
   - `photo-1.jpg` (Featured portrait photo)
   - `photo-2.jpg` (Cozy moment / coffee / candid)
   - `photo-3.jpg` (Smiling / laughing portrait)
   - `photo-4.jpg` (Evening / outdoor / travel)
   - `photo-5.jpg` (Cozy corner / candid)
   - `photo-6.jpg` (Favorite memory together)

2. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.

3. To update captions, handwritten notes, or add more photos:
   - Open `src/data/scrapbookData.ts`
   - Edit the titles, captions, annotations, and photo paths!
